# Animal Helping Foundation Web

A modern, responsive, pixel-perfect React + Vite web application for Animal Helping Foundation.

## Features
- **Hero Section**: Dynamic funding tracker, headline, badges, and CTA action buttons.
- **Causes Section**: 6 campaign cards with high-definition imagery and donor metrics.
- **About Us & Impact**: NGO history, community statistics, and impact cards.
- **Recognition & Emergency Banners**: Featured media, rescue stats, and full-width Nepal Floods banner.
- **Live Donor Feed & Stories**: Real-time donor activity list and community blog stories.
- **FAQ & Footer**: Interactive accordion items, contact info, head office location, and sleeping dog footer.

## Tech Stack
- React 18 / Vite 8
- Lucide Icons & Custom SVG graphics
- Custom CSS Design System

## Getting Started
```bash
npm install
npm run dev
```
